# 常见问题

**没有声音？** 先安装分享包中的 `01_离线日语语音_1.13.8.apk`，再在伴读点“设置 → 日语朗读 → 试听日语”。需要切换时点“选择语音引擎”，直接在伴读里选 `TTS Engine: Next-gen Kaldi`。声音已包含，无需另下。

**没有中文？** 进入伴读“设置 → 翻译服务”填自己的 DeepSeek API 密钥并保存，测试连接。语音软件负责朗读，不提供翻译密钥。

**读不到日文？** 把游戏放系统主屏，开始识别并允许录屏，再框选台词区域。

**安装冲突？** 先备份学习资料，保留旧应用，确认下载的是本系列更新；不要直接卸载丢失数据。
**旧版点选择语音引擎退出？** 覆盖安装 0.37 或更高版本，选择已改为伴读内列表。若仍退出，请反馈机型、安卓版本和出现问题的步骤。
