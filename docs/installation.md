# 下载与安装

[点击下载完整包](https://github.com/hzz19980728-cell/ScreenStudy/releases/download/v0.35/ScreenStudy-0.35-Share.zip)，解压后先装 `01_离线日语语音_1.13.8.apk`，再装 `02_双屏日语伴读_0.35.apk`。

安装时按系统提示允许当前文件管理器安装应用。桌面名称是“双屏日语伴读”。老用户直接覆盖安装伴读，保留学习数据。

打开伴读 → 设置 → 翻译服务 → 填自己的 DeepSeek API 密钥并保存；地址和模型保持默认。密钥申请：https://platform.deepseek.com/

游戏放主屏，伴读放副屏 → 点最上方识屏图标 → 开始识别 → 允许录屏 → 识别范围框住台词。

日语声音已包含在另一个 APK 内。没声音时，系统设置搜索“文字转语音”，首选引擎选 `TTS Engine: Next-gen Kaldi`。
