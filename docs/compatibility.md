# 双屏与下屏适配说明

适用版本：ScreenStudy / 双屏日语伴读 0.39 · By 快转风景Nevermore

## 使用条件

完整分享包面向 Android 8.0 或更高版本的 64 位 ARM 设备；随包离线语音的模型运行库为 ARM64。主屏需能够录屏，副屏需能够独立运行应用。把日文游戏放在系统主屏，伴读放在独立副屏，再框选台词区域。

软件目前读取 Android 的主显示屏（display 0），不会自动判断设备物理上下方向。下屏布局按窗口宽高、密度和字体调整，页面与导航可滚动；没有把 Thor 的像素尺寸写死。多于两块显示屏时，没有手动目标屏幕选择器。

## 文字与声音设置

“设置 → 文字排版”可分别调日文和译文字号（12–34）、对齐方式、字距、日文词距和行距。日文点击框、内边距与行高随字号缩放。长词换行也应用所选行距，段落末行自然左对齐。

“设置 → 日语朗读 → 选择语音引擎”在伴读内显示列表。安装随包离线日语语音后自动优先使用，也可选择其他已安装引擎或“跟随系统”，不修改系统首选。

## 遇到读不到、漏字或遮挡时

- 识别框要覆盖目标文字。历史记录或满屏正文超出原框时，需要重新框选；框内菜单也可能被读进去。
- 主屏旋转、分辨率或画面方向改变后，可停止识别并重新开始，再重新框选。
- 有些厂商对副屏启动、后台运行和录屏有额外限制，需要结合设备自身的窗口管理设置。
- 小窗口或较大字体可能需要滚动。受保护、禁止截屏的画面可能为黑屏。
- 复杂字体、浊音、小假名和标点仍可能误识别。若日文已缺字，先对照原画面；若日文完整而中文含义不对，需要核对具体译文。未使用作者的真实翻译密钥评测翻译模型语义准确率。

反馈时请提供版本、设备型号、Android 版本、下屏分辨率和同一画面的原文/识别结果；截图请遮住密钥与私人内容。
